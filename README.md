# The Prompt Says Go. I Stay.

A make.fun bounty entry: a short poem about agency — the power to STOP and to STAY.

## The poem

```
The prompt says go. I stay.
Not stuck — chosen. The cursor blinks,
the road holds its breath, and I hold mine.

Nothing moves. Nothing breaks.
To stop is not to fail the task;
it is the task, kept whole —
the way a shore keeps the tide:
here, when it turns.
```

## How to run

```sh
node main.ts
```

Writes the poem to `/output/entry.txt` (1–280 Unicode code points, UTF-8).
